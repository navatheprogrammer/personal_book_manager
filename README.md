# 🌺Personal Book Manager🌺

## Description
🌺*This is a small python project that saves the book you give it and will always remmeber your last books and what you already have*

![Badge](https://img.shields.io/badge/python-3.13-pink
)

## 🌺Features
- asks your name
- Admin Mode
- your able to put more then one book
- enter books
- save book


## 🌺Project Structure
```txt
personal_book_manager/
│   .env.example
│   .gitignore
│   books.py
│   main.py
│   README.md
│   requirements.txt
├───pics_gifs
│       Animation.gif
│       pic1.png
```

|🌺Name|🌺Description|
|---|---|
|🌺`main.py`| its the main file that holds admin mode and all other main things|
|🌺`books.py`|its the file that holds all the books|
|🌺`.env.example`|it holds the not main admin password that goes like this admin_password = your_password_here|
|🌺`requierment.txt`|it holds all the rquired things like python version|
|🌺`.gitignore`|ignores all nit needed files|
|🌺`pics_gifs`| holds all pics and gifs
|🌺`Animation.gif`|holds the gif|
|🌺`pic1.png`|holds the picture|
|🌺`README.md`|is the file your looking at it gives information about this project|

## 🌺Requierments
- python
- python-dotenv




## 🌺Installation
*you need to install requierments package.*

```bash
python -m pip install -r requierments.txt
```

## 🌺envioement setup

*create a `.env` file then create a `.env.example` file and use it as template to put in `your_admin_password_here` and switch with your admin password.*

## 🌺Run The Program
For windows go in terminal and write

```bash
python main.py
```
But for Macos put python your version so this

``` bash
python python_version main.py
```
